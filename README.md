# Tanay Joshi | Trainer Portfolio

A Pokémon-inspired pixel portfolio: title screen, trainer card, skills as moves, a searchable project Dex, contact and a Day/Night mode. Plain HTML, CSS and JS, no build step.

## Put it online (GitHub Pages)

1. Sign in to GitHub as **TanayJoshi-XR** and create a new **public** repository named exactly `TanayJoshi-XR.github.io`.
2. On the empty repo page click **uploading an existing file**, drag in everything from this folder (`index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder), then **Commit changes**.
3. Open **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at **https://tanayjoshi-xr.github.io**.

## Edit the content

Everything personal is in the `PROFILE` block at the top of `script.js`: name, bio, email, skills, badges, links and projects. To list projects straight from GitHub instead, empty the `projects` array and the Dex fills itself from public repos.

## Run locally

Open `index.html`, or run `python3 -m http.server` here and visit http://localhost:8000.
